# ИС «Фотостудия» («Кадр») — модуль управления заявками

## Запуск
1. python database.py
2. python app.py

## Функциональность
- создание заявки (кнопка «Добавить запись»);
- расчёт стоимости;
- проверка доступности слота в расписании;
- оплата и смена статусов («Новый» → «Ожидание» → «Подтвержден»);
- уведомление фотографу.

## Примечание
В модуле намеренно оставлены 3 контролируемых дефекта для МДК 05.03.
